# Java OOP From Beginner to Advanced

A structured Java Object-Oriented Programming learning repository. It starts with basic Java concepts and gradually moves to OOP principles, advanced topics, practice questions, and mini projects.

## Learning path

1. Java Basics
2. Classes and Objects
3. Constructors
4. Encapsulation
5. Inheritance
6. Polymorphism
7. Abstraction
8. Interfaces
9. Method Overloading
10. Method Overriding
11. Access Modifiers
12. Static and Final
13. Exception Handling
14. Arrays and OOP
15. Collections
16. File Handling
17. Mini Projects

## How to run

Install a JDK (Java Development Kit), then open a terminal in the folder containing a `.java` file.

```bash
javac Main.java
java Main
```

Some examples use a public class whose name matches the file name. Compile and run each example separately.

## Repository rules

- Each topic has a short explanation.
- Examples are kept simple and beginner friendly.
- Practice questions are included after major topics.
- Mini projects combine concepts from multiple chapters.
