# Practice Questions

## Java Basics
1. Print your name, age, and department.
2. Take two numbers from the user and display their sum.
3. Take marks and display a grade using if/else.
4. Print the multiplication table of a number.
5. Write a method that returns the largest of two numbers.

## Classes and Objects
1. Create a `Car` class with brand, model, and year.
2. Create two `Book` objects and display their details.
3. Create an `Employee` class with a method to calculate yearly salary.

## Constructors
1. Create a `Laptop` class with a no-argument constructor.
2. Create a `Product` class with a parameterized constructor.
3. Add two constructors to a `Rectangle` class and calculate area.
